## What we build | 核心能力

### Ccloud | 碳云

An integrated carbon management platform for corporate carbon accounting, product carbon footprints, supply-chain carbon management, carbon disclosure, and decarbonization workflows.

面向企业碳核算、产品碳足迹、供应链碳管理、碳披露与减排工作的数字化一体化碳管理平台。

### CCDB | 碳排放因子数据库

Professional carbon emission factor data and tools that support factor search, carbon accounting, product carbon footprints, and sustainability applications.

为排放因子查询、碳排放核算、产品碳足迹及可持续发展应用提供专业的数据与工具支持。

### Carbon Agent | AI 碳管理入口

[Carbon Agent](https://agent.carbonstop.com) is the web destination for exploring CCDB data and viewing emission factor details. CCDB is the data capability; factor detail pages are hosted within Carbon Agent, not on a separate CCDB website.

[Carbon Agent](https://agent.carbonstop.com) 是探索 CCDB 数据与查看排放因子详情的网站入口。CCDB 提供因子数据能力，因子详情页面位于 Carbon Agent 中，目前没有独立的 CCDB 网站。

When CLI, Skill, or MCP query results include factor detail links, follow those links to view the corresponding factors in Carbon Agent. Data availability depends on account permissions and licensing; visiting or signing in does not guarantee access to every value.

通过 CLI、Skill 或 MCP 查询时，可点击结果返回的因子详情链接，进入 Carbon Agent 查看对应因子。数据可见范围取决于账号权限与数据许可，访问或登录不代表所有数值均可解锁。

### AI & Open Source | AI 与开源

We bring professional carbon data capabilities to developers and AI agents through a standalone CLI, reusable Agent Skills, and the Model Context Protocol (MCP).

我们通过独立 CLI、可复用的 Agent Skills 与模型上下文协议（MCP），将专业碳数据能力接入 AI Agent 与开发者生态。

## Open-source projects | 开源项目

<table>
<tr>
<td width="33%" valign="top">

### [ccdb-cli](https://github.com/carbonstop/ccdb-cli)

Query CCDB emission factors from your terminal or an Agent with command-execution support. Available through npm and standalone binaries.

在终端或具备命令执行能力的 Agent 中查询 CCDB 排放因子，提供 npm 安装与独立二进制。

</td>
<td width="33%" valign="top">

### [ccdb-mcp](https://github.com/carbonstop/ccdb-mcp)

A Model Context Protocol server for CCDB factor search and detail retrieval, with local stdio and server-side Streamable HTTP support. See the repository for Gateway-based remote deployment and authorization.

提供 CCDB 因子搜索与详情查询的 MCP Server，支持本地 stdio 与服务端 Streamable HTTP。远程部署及授权采用 Gateway 接入架构，详见仓库说明。

</td>
<td width="33%" valign="top">

### [skills](https://github.com/carbonstop/skills)

An Agent Skill that uses CCDB CLI to search, compare, and select emission factors, preserving returned Carbon Agent detail links. Requires command execution, the CLI, and valid authorization.

配合 CCDB CLI 使用的 Agent Skill，指导因子查询、比较与选择，并保留返回的 Carbon Agent 详情链接。需要宿主命令执行能力、CLI 和有效授权。

</td>
</tr>
</table>

For web access, start with [Carbon Agent](https://agent.carbonstop.com). For terminal use, choose CLI; for a Skill-enabled Agent with command execution, choose Skill + CLI; for an MCP host, choose the independent MCP integration. Open-source licenses cover the code, not unrestricted CCDB data access or redistribution.

网页使用从 [Carbon Agent](https://agent.carbonstop.com) 开始；终端用户选择 CLI；支持 Skill 且能执行命令的 Agent 选择 Skill + CLI；MCP 宿主使用独立 MCP 接入。开源许可适用于代码，不代表获得 CCDB 数据的无限制访问或再分发权。
